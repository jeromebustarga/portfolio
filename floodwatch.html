Flood Watch PH

An anomaly-detection system that flags statistically unusual Philippine government flood-control contracts, with a dashboard to explore the results and a Tagalog/English assistant to ask questions about them.

The model

An unsupervised Isolation Forest scores every project from 0 to 1 on how statistically unusual it is. The signal comes from engineered features rather than any labelled set of known-bad contracts, because no such labelled set exists.

Features it scores on

  • Budget size and where a project sits in the overall budget percentile.
  • Round-number pricing, where an approved amount lands suspiciously evenly.
  • Repeated identical descriptions and amounts across separate contracts.
  • Contractor concentration within a region or district.

Around 2,000 projects scored high enough to be flagged. Run blind against the real data, the highest-scoring contractors turned out to be firms already under official investigation — which is what validates the approach. The model was not told who they were; it found them from the shape of the contracts alone.

How to read a flag

A flag means statistically unusual, worth review. It is not a finding of wrongdoing, and this project makes no such claim about any company. Official findings are for the COA, the ICI and the Ombudsman to make. The underlying data is public and CC0.

Asking it questions

A retrieval-augmented assistant sits on top of the same records. Multilingual embeddings (multilingual-e5-small) index all 68,000 projects for retrieval, and a multilingual model answers in Tagalog or English, grounded only in the records actually retrieved rather than on its own recollection.

That grounding matters here more than usual: an assistant that improvises about public spending would be worse than no assistant at all.

Getting the data usable

  • Ingested a 139 MB government dataset and filtered it down to flood control.
  • Recovered missing region and province for roughly 35,000 rows by reverse geocoding from coordinates, since the source left them blank.
  • Precomputed anomaly scores into the served data, so the dashboard stays responsive instead of scoring on every request.

Source: the DPWH transparency portal, via BetterGov.ph, released CC0.
