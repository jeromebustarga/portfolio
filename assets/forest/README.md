# Put your hologram-forest PNG art in THIS folder

The site (index.html) looks for these exact filenames (keep the spaces and
parentheses). Any file that is missing silently falls back to a drawn SVG,
so you can upload them in any order / a few at a time.

## Ground flora (transparent PNGs)
coconut.png        (palm)
bush.png           (trees/pines)
vine.png           (hanging vines)
plant.png, plant (1).png ... plant (19).png   (shrubs/ferns/grass/flowers/mushrooms)

## Sky (full-colour art)
cloud.png, cloud (1).png ... cloud (4).png
crystal.png, crystal (1).png ... crystal (5).png   (orbs/moons)
planet.png, planet (1).png
sun.png
island.png, island (1).png ... island (4).png      (mountains/islands)
